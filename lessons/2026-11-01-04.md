# 第4课｜注意力机制：模型怎样结合上下文理解一个词？

日期：2026-11-01

> 归档整理版：根据当前对话可读取的课程进度摘要及问答整理，不是原始逐字讲义。教学例子不代表真实个人记录。

位置指 Token 在序列中的索引，不是向量坐标、注意力头或网络层。

按行向量约定，一个位置 x 经参数矩阵得到：

q=xW_Q，k=xW_K，v=xW_V。

某位置 i 的 q_i 与各可见位置的 k_j 点积，除以 sqrt(d_k)，经 Softmax 转为权重 a_ij，再计算 o_i=Σ_j a_ij v_j。不是只让一个 Token 的 q 和自己的 k、v 运算。

## 数值教学例子
A、B 是两个 Token 位置。假设 B 对 A、B 的最终注意力权重为 0.33、0.67，v_A=[2,0]、v_B=[0,2]，则 B 的注意力输出约为 [0.66,1.34]。这些权重是假设值，不是实际模型输出。

## 用户讨论
- “A、B 是因为多头吗？相当于 Token 吗？”——这里是位置，非两个头。
- “多个 QKV、增加维度还是多套 Transformer？”——多头是不同投影参数的并行注意力计算，并非多套完整 Transformer。
- “把原向量拆开再合并？”——标准多头中各头可以通过自己的矩阵投影完整输入到较小维度，不是简单各取原输入的一段；拼接各头输出后再经输出投影。实现中可先做一个大矩阵投影，再拆分投影结果。
