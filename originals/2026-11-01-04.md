# 第4课：注意力机制——模型怎样结合上下文理解一个词？

今天约 8分钟阅读＋2分钟练习。学完后，你能说清注意力的三个步骤：计算匹配程度、分配权重、组合信息，并理解常见的Q、K、V分别做什么。

上一课讲过，Embedding能把文字表示成向量。但文字的意思经常依赖上下文。比较这两句话：

> 我在水果店买了苹果。
这家发布新手机的公司叫苹果。



“苹果”相同，前面的线索却让我们作出不同理解。模型也需要一种机制，让当前位置的表示吸收其他位置的信息。**注意力机制（Attention）就是实现这种信息交流的重要方式。**

可以先把注意力理解为：带着当前需求，从已有信息中提取内容。

想象你要整理一次训练记录，手边有日期、器械、组数、饮食等信息。现在需要计算训练量，你会更多参考重量、次数和组数。

模型中的注意力也会给不同位置分配不同权重，然后组合它们携带的信息。不过，“需要”“参考”只是类比：实际过程是向量和矩阵运算，不代表模型有人的意识。

这里还有一个重要区别：普通搜索常返回几条独立结果；注意力通常会把多个位置的信息按权重混合成一个新向量。

要理解计算过程，先认识Q、K、V。

在标准自注意力中，每个位置的当前表示，会通过不同的、训练得到的线性变换，产生三类向量：

| 名称 | 英文 | 可以怎样理解 |
|---|---|---|
| Q：查询 | Query | 当前这个位置用来寻找什么信息 |
| K：键 | Key | 这个位置用来与查询匹配的特征 |
| V：值 | Value | 匹配之后，实际参与组合的信息 |


Q与K用于计算匹配分数，V用于形成输出。三者都是数字向量，并不是模型真的写出了三句说明。它们来自同一段序列时，这种机制称为自注意力（Self-Attention）。

可以借用图书馆的比喻：Q像检索需求，K像用于匹配的索引，V像取回的内容。但真实模型会一起学习这些表示，并没有人事先规定某个数字必须表示“水果”或“训练”。

下面走一遍实际计算的基本顺序。

以“我在水果店买了苹果”为例，暂时观察“苹果”所在位置：

1. 算匹配分数。 用该位置的Q，与允许关注位置的K分别计算点积，并进行缩放。
2. 变成权重。 使用Softmax，将分数转换为非负、总和为1的权重。
3. 组合信息。 用这些权重乘各位置的V，再相加，得到该注意力头的输出。

这里描述的是省略训练时Dropout的基本计算。Softmax的作用，是让不同位置的分数形成一组相对权重。

现在做一个能手算的示例。以下切分、权重和向量全部是教学假设，不是真实模型测量。为简化，只保留三个来源位置；实际计算通常还包含自身及其他允许的位置。

| 来源位置 | 假设的注意力权重 | 假设的V向量 |
|---|---|---|
| 水果店 | 0.7 | [1, 0] |
| 买了 | 0.2 | [0, 1] |
| 我 | 0.1 | [0.5, 0.5] |


组合结果为：

\[
0.7[1,0]+0.2[0,1]+0.1[0.5,0.5]=[0.75,0.25]
\]

第一项是 \(0.7+0+0.05=0.75\)，第二项是 \(0+0.2+0.05=0.25\)。

这就是“加权求和”：每个来源贡献一部分信息。

得到的 [0.75,0.25] 仍然是一个中间向量。 它不等于“75%是水果、25%是公司”，也没有直接生成答案。它还要经过后续网络处理，才会影响最终输出。

如果上下文换成公司发布手机，计算出的表示和权重可能不同，于是同样的“苹果”可以获得不同的上下文表示。关键变化来自输入内容，不需要为每一句新话重新训练模型。

一个注意力头，也不需要包办所有关系。

真实模型常使用多个注意力头，让不同组计算有机会捕捉不同关系，再合并结果。有的头可能呈现与语法、位置或指代相关的模式，但不能预设“第一头专管语法、第二头专管事实”。这些作用通常通过训练形成，也不一定有清晰分工。

今天只需要理解单个头的核心过程，完整Transformer结构留到下一课。

模型能够关注哪些位置，还受规则限制。

在常见的自回归生成模型中，某个位置通常只能利用自身及之前的位置，不能偷看后面的内容。这由**因果掩码（Causal Mask）**实现：不允许连接的位置，在权重计算中被屏蔽。

例如，模型正在根据“我在水果店买了”预测后续文字，就不能把尚未生成的“苹果”当成已知线索。

因此，“注意力能结合上下文”不等于“任何位置都能任意看到整句话”。具体范围取决于模型结构和掩码。

还要避免把注意力权重当作答案解释。

前面的0.7，只表示这个简化计算中的混合权重。不能据此断言“最终答案有70%由水果店决定”，更不能说“模型有70%的把握”。

最终结果还受到V的内容、其他注意力头、其他网络层等因素影响。相关研究也发现，不同注意力分布可能产生相近预测，因此单张注意力图不能直接当作完整的因果解释。

这与前几课连起来，就能理解：一项限制即使进入上下文，模型仍可能没有正确执行。注意力提供了信息交流机制，但正确遵守要求还需要整个模型及后续检查共同完成。

现在做一个约2分钟的小练习，分成计算与解释两步。

假设某个注意力头只组合两个来源：

- 来源A的V是 [2, 0]，权重为0.25。
- 来源B的V是 [0, 4]，权重为0.75。

先算出输出向量，再用一句话说明：B的权重为0.75，为什么不能解释成“B有75%的概率是正确答案”？

——先独立思考，再看参考——

计算结果是：

\[
0.25[2,0]+0.75[0,4]=[0.5,3]
\]

0.75控制的是B的向量在这一步如何参与混合。它既没有检验B的事实真伪，也不是对某个答案正确性的概率估计。

今天记住三点：

- Q和K计算匹配程度，V提供实际组合的信息。
- 注意力按权重汇集上下文，产生中间表示。
- 注意力权重不等于正确率，也不能单独解释最终答案。
